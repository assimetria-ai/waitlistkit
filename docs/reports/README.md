# Product Reports

All research, analysis, and periodic reports for this product.

## Structure
- `competitor-analysis/` — Competitor research and comparisons
- `market-research/` — Market size, ICP, trends
- `qa-reports/` — QA audit results
- `performance/` — Performance benchmarks and optimization reports

## Format
Reports are Markdown files: `YYYY-MM-DD-{type}-{title}.md`
